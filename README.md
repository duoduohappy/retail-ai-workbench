## 立即打开

- 推荐：双击本目录的 `启动工作台.cmd`，会使用 Python 启动服务并打开浏览器。
- 或执行 `python server.py --open`，访问 http://127.0.0.1:8787 。仅监听本机。
- 无 Python 时，可以直接打开 `dist/index.html`；数据、计算、脚本模板、导出与项目管理无需联网。浏览器可能限制 file 协议下的视频合成或本地存储，此时使用本地服务或内置MP4样片。
- 标准浏览器运行无需 npm 安装，也不依赖外部CDN。

## 数据与可复现评估

- 固定种子：20261123。
- 观察截止：2026-11-22；交易历史365天；6家门店、24种商品、800名会员。
- 37,704笔订单、70,579行订单商品；金额以整数分保存。
- SQLite全期净销售额：138,098,083分；商品成本：73,660,970分。
- 预设情景：东区重点饮品零库存、转化率下降、零食品类折价促销、日用品高库存，以及过期活动与同源转载。
- `python scripts/generate_data.py` 可重建 `retail.sqlite`、`dist/data.js` 和 `docs/evaluation.json`。
- 推荐训练截止2026-10-25，测试2026-10-26至2026-11-22；315名符合条件会员；K=5。模型与热门基线均排除训练期已购。
- 离线NDCG@5：热门基线0.3029，商品篮关联0.3542。模拟数据预设偏好和搭配机制，这些结果只证明链路可运行，不代表真实商业提升。

推荐评估仅使用英国正向、有会员ID的购买记录，按时间切分、与热门基线使用相同候选和已购过滤，并显示候选覆盖率和用户配对Bootstrap区间。完整口径及结果见[真实公开数据评估](docs/真实公开数据评估.md)。该数据没有真实毛利、库存、门店客流或活动分流字段，不用模型补造这些指标，也不代表当前市场或目标企业业绩。

## 可选：接入Qwen4-Max生成脚本和研究报告

默认运行不需要任何密钥。若需要测试模型脚本，在启动服务的进程环境中设置：

```powershell
$env:RETAIL_LLM_ENDPOINT = 'https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions'
$env:RETAIL_LLM_MODEL = 'qwen4-max'
# 仅在自己电脑安全设置RETAIL_LLM_API_KEY，不提交到Git。
python server.py --open
```

接口需要兼容 `messages` 请求与 `choices[0].message.content` 响应。密钥只在本地服务环境中读取，不写入浏览器或源码。外部地址需要HTTPS和密钥；本地Ollama可使用HTTP与空密钥，例如配置 `http://127.0.0.1:11434/v1/chat/completions` 及本机已安装模型名称。项目不会自动下载或启动模型。

脚本请求会发送当前商品资料、卖点、目标人群及活动文本至你配置的服务。商品名称从SQLite复核，模型仅润色字幕与配音稿；价格字段保留，输出仍需人工核对。接口检查同源、Host、请求大小、字段和输出结构，明确区分未配置、输入错误、上游超时和格式错误。

Render需要在Environment配置模型地址、模型ID、API Key及另设的RETAIL_DEMO_ACCESS_CODE；公网调用必须提供演示访问码，模型Key始终留在后端。默认每进程最多20次调用尝试、输出上限1800 Token；进程重启会重置次数，不能替代云端“免费额度用完即停”。详细步骤见[千问接入与免费额度](docs/千问接入与免费额度.md)和[环境变量示例](.env.example)。

右上角“AI服务”读取配置不调用模型；点击“实际验证模型连接”才发送短请求。研究报告同时记录模型、耗时、Token与来源，未知来源或不匹配摘录会被拒绝，失败时保留已有报告。实际云端连通仍需在配置后手动验证；受控替身测试不能代替真实账号联通。静态托管不提供Python API，本地服务与Render Python服务可提供。

## 文件结构

```text
dist/               可直接运行与部署的静态应用
  index.html        页面骨架
  core.js           金额、分析、推荐、促销及证据规则
```

第二版主要代码：`dist/advanced.js` 提供问题检索、样本规划、CSV、实验统计、敏感性与快照；`dist/advanced-ui.js` 提供对应交互；所有模块都调用共享的数据与计算函数。

第三版的`dist/real-ui.js`提供公开数据界面和模型操作，`scripts/build_public_benchmark.py`可从官方源重建公开数据结果；重建依赖仅列在`requirements-analysis.txt`，线上演示不需要安装Excel库或下载原始数据。

## 试点评估CSV

每用户只出现一次，金额以元表示。`net_sales` 为观察期净销售，`variable_cost` 为对应变动成本，`campaign_cost` 为分摊的额外活动费用；注意避免优惠或费用重复扣减。

```csv
user_id,group,converted,net_sales,variable_cost,campaign_cost
anonymous-001,control,1,50,28,0
anonymous-002,control,0,0,0,0
anonymous-003,treatment,1,60,34,1
anonymous-004,treatment,0,0,0,1
```

小样本只用于验证格式。正式判断需要预先确定分流、样本、周期、主指标和停止规则；系统不会将导入文件自动认定为可信随机实验。

项目仅用于本人面试演示。浏览器存储不跨设备同步；清理站点存储会丢失手动任务和证据。进入真实业务前，需要完成数据接入、身份与权限、审计、来源验证、实验与运维建设。
