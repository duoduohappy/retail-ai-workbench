# RETAIL OS · 零售经营与AI决策工作台

![CI](https://github.com/duoduohappy/retail-ai-workbench/actions/workflows/ci.yml/badge.svg)

当前版本：**v0.2.0**。第二版补充按问题检索、证据不足处理、价格敏感性分析、实验样本与结果评估、版本关联的内容核对、运行快照，以及实际AI静态素材与有声视频案例。

针对“零售数字化与AI技术主管”岗位自主开发的面试演示项目。全部门店、商品、会员、竞品和交易均为虚构，不使用目标企业内部资料。

## 立即打开

- 推荐：双击本目录的 `启动工作台.cmd`，会使用 Python 启动服务并打开浏览器。
- 或执行 `python server.py --open`，访问 http://127.0.0.1:8787 。仅监听本机。
- 无 Python 时，可以直接打开 `dist/index.html`；数据、计算、脚本模板、导出与项目管理无需联网。浏览器可能限制 file 协议下的视频合成或本地存储，此时使用本地服务或内置MP4样片。
- 标准浏览器运行无需 npm 安装，也不依赖外部CDN。

建议演示：驾驶舱诊断 → 推荐商品 → 促销模拟 → 生成活动内容 → 核对脚本 → 合成视频 → 研究证据排除 → 创建试点与汇报。

## 可选：接入真实大模型生成脚本

默认运行不需要任何密钥。若需要测试模型脚本，在启动服务的进程环境中设置：

```powershell
$env:RETAIL_LLM_ENDPOINT = 'https://你的服务地址/v1/chat/completions'
$env:RETAIL_LLM_MODEL = '你的模型名称'
$env:RETAIL_LLM_API_KEY = '你的密钥'
python server.py --open
```

接口需要兼容 `messages` 请求与 `choices[0].message.content` 响应。密钥只在本地服务环境中读取，不写入浏览器或源码。外部地址需要HTTPS和密钥；本地Ollama可使用HTTP与空密钥，例如配置 `http://127.0.0.1:11434/v1/chat/completions` 及本机已安装模型名称。项目不会自动下载或启动模型。

脚本请求会发送当前商品资料、卖点、目标人群及活动文本至你配置的服务。商品名称从SQLite复核，模型仅润色字幕与配音稿；价格字段保留，输出仍需人工核对。接口检查同源、Host、请求大小、字段和输出结构，明确区分未配置、输入错误、上游超时和格式错误。

真实模型调用未在交付环境中验证，因为当前未配置服务和密钥。私有托管版本是静态应用，不包含此本地API；模板脚本和其他演示功能可运行。

## 试点评估CSV

每用户只出现一次，金额以元表示。`net_sales` 为观察期净销售，`variable_cost` 为对应变动成本，`campaign_cost` 为分摊的额外活动费用；注意避免优惠或费用重复扣减。

```csv
user_id,group,converted,net_sales,variable_cost,campaign_cost
anonymous-001,control,1,50,28,0
anonymous-002,control,0,0,0,0
anonymous-003,treatment,1,60,34,1
anonymous-004,treatment,0,0,0,1
```

小样本只用于验证格式。正式判断需要预先确定分流、样本、周期、主指标和停止规则；系统不会将导入文件自动认定为可信随机实验。

项目仅用于本人面试演示。浏览器存储不跨设备同步；清理站点存储会丢失手动任务和证据。进入真实业务前，需要完成数据接入、身份与权限、审计、来源验证、实验与运维建设。
