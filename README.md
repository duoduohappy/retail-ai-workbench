# RETAIL OS · 零售经营与AI决策工作台

针对“零售数字化与AI技术主管”岗位自主开发的面试演示项目。全部门店、商品、会员、竞品和交易均为虚构，不使用目标企业内部资料。

## 立即打开

- 推荐：双击本目录的 `启动工作台.cmd`，会使用 Python 启动服务并打开浏览器。
- 或执行 `python server.py --open`，访问 http://127.0.0.1:8787 。仅监听本机。
- 无 Python 时，可以直接打开 `dist/index.html`；数据、计算、脚本模板、导出与项目管理无需联网。浏览器可能限制 file 协议下的视频合成或本地存储，此时使用本地服务或内置MP4样片。
- 标准浏览器运行无需 npm 安装，也不依赖外部CDN。

## 六个模块与操作

| 模块 | 可运行能力 | 当前边界 |
| --- | --- | --- |
| 经营驾驶舱 | 时间和门店筛选、销售与毛利、精确代数分解、缺货记录、订单下钻与CSV导出 | 日快照与固定成本；分解不代表因果 |
| 市场与竞品雷达 | 同规格周度价差、品类筛选、价格模拟联动、研究简报 | 竞品及外部资料为模拟，未实时采价 |
| 会员与策略中心 | RFM规则分层、搜索、商品篮关联推荐、库存过滤、时间切分评估、促销模拟 | 非线上推荐系统；弹性为用户假设 |
| AIGC内容工厂 | 关联商品与活动、生成模板脚本、审核状态、15秒MP4样片、浏览器合成WebM、脚本导出 | 视频为排版模板，无生成式画面或合成配音；可选接入大模型脚本 |
| 市场研究助手 | 添加资料、时效检查、同源去重、引用追溯、结构化报告导出 | 无联网检索，用户来源未独立核实，默认不调用模型 |
| 项目与价值管理 | 从异常或策略创建任务、负责人和预算、状态持久化、假设ROI、管理摘要及90天方案 | 数据存于当前浏览器，非多人项目管理服务 |

建议演示：驾驶舱诊断 → 推荐商品 → 促销模拟 → 生成活动内容 → 核对脚本 → 合成视频 → 研究证据排除 → 创建试点与汇报。

## 数据与可复现评估

- 固定种子：20261123。
- 观察截止：2026-11-22；交易历史365天；6家门店、24种商品、800名会员。
- 37,704笔订单、70,579行订单商品；金额以整数分保存。
- SQLite全期净销售额：138,098,083分；商品成本：73,660,970分。
- 预设情景：东区重点饮品零库存、转化率下降、零食品类折价促销、日用品高库存，以及过期活动与同源转载。
- `python scripts/generate_data.py` 可重建 `retail.sqlite`、`dist/data.js` 和 `docs/evaluation.json`。
- 推荐训练截止2026-10-25，测试2026-10-26至2026-11-22；315名符合条件会员；K=5。模型与热门基线均排除训练期已购。
- 离线NDCG@5：热门基线0.3029，商品篮关联0.3542。模拟数据预设偏好和搭配机制，这些结果只证明链路可运行，不代表真实商业提升。

## 可选：接入真实大模型生成脚本

默认运行不需要任何密钥。若需要测试模型脚本，在启动服务的进程环境中设置：

```powershell
$env:RETAIL_LLM_ENDPOINT = 'https://你的服务地址/v1/chat/completions'
$env:RETAIL_LLM_MODEL = '你的模型名称'
$env:RETAIL_LLM_API_KEY = '你的密钥'
python server.py --open
```

接口需要兼容 `messages` 请求与 `choices[0].message.content` 响应。密钥只在本地服务环境中读取，不写入浏览器或源码。脚本请求会发送当前商品资料、卖点、目标人群及活动文本至你配置的服务。模型只润色字幕与配音稿，价格和商品ID由本地记录保留；结果仍需人工审核。

真实模型调用未在交付环境中验证，因为当前未配置服务和密钥。私有托管版本是静态应用，不包含此本地API；模板脚本和其他演示功能可运行。

## 文件结构

```text
dist/               可直接运行与部署的静态应用
  index.html        页面骨架
  core.js           金额、分析、推荐、促销及证据规则
  app.js            界面、模块联动、导出、浏览器视频合成
  data.js           可复现业务与模型快照
  assets/           MP4样片、预览图及分镜图
retail.sqlite       关系型业务数据与net_sales视图
server.py           本地静态服务与可选模型脚本接口
scripts/            数据与视频生成工具
tests/              计算、数据一致性与证据边界测试
docs/               需求架构、评估数据、面试演示稿、验收记录
```

项目仅用于本人面试演示。浏览器存储不跨设备同步；清理站点存储会丢失手动任务和证据。进入真实业务前，需要完成数据接入、身份与权限、审计、来源验证、实验与运维建设。
