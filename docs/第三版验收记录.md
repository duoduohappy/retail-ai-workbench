# v0.3.0验收记录

日期：2026-11-23。

## 新增能力

1. 真实公开数据：从UCI官方源校验ZIP哈希，处理541,909行历史交易，生成经营汇总、推荐对照、候选覆盖率与Bootstrap区间。汇总与页面、JSON和来源记录一致。原始会员ID不进入交付仓库。
2. 模型接口：后端支持Qwen4-Max兼容接口，生成脚本与引用研究报告；健康检查不推理，只有显式操作才调用模型。模型ID、耗时、Token用量与本项目请求ID随结果返回。
3. 报告质量检查：拒绝未知来源、非原文引用、空证据及错误结构。报告明确标注历史数据、待验证假设和人工复核要求。引用匹配不证明语义正确。
4. 调用保护：公网使用独立演示访问码，模型Key留在后端；默认每进程最多20次尝试、最多两个并发调用、输出最多1800 Token。Qwen4显式关闭思考；免费额度用尽不重试或自动换模型。次数限制不能替代云端用完即停。
5. 页面处理：访问码只在内存保留；失败保留已有报告；输入改变后丢弃迟到结果；报告导出按各自请求ID关联，输出内容经HTML转义。

## 远程与实际调用边界

- GitHub Actions同时检查Linux、Windows；每次提交的实际结果见[Actions](https://github.com/duoduohappy/retail-ai-workbench/actions)。本地通过不能代替远程结果。
- 模型HTTP测试使用受控替身，不消耗用户真实额度；尚未获得运行环境配置，不能声称已实际调用用户的Qwen4-Max。配置后需从“AI服务”手动验证，并观察真实用量和结果。
- 本版本未代为发布Render；用户手动部署最新提交并填写服务环境变量。静态托管无法运行模型后端。
- JSDOM属于DOM集成测试，不是真实浏览器视觉、视频播放或下载兼容性验收；本版本仍需部署后浏览器复核。
- 真实数据为2010—2011年英国在线零售历史记录，不包含成本、库存、门店客流或随机实验。推荐离线改善不是销售增长证明。
- 没有实时联网检索、实时生成式视频、企业身份权限、多人协作或服务端防篡改审计。页面任务和运行快照仍保存在浏览器。
