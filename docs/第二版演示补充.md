# v0.2.0 演示补充

## 研究可信度

输入“东区库存缺货与补货”，应主要检索到库存记录E03。再输入“饮料促销价格与活动”，观察价格资料与过期/同源记录的变化。最后输入资料库不覆盖的问题，展示资料不足状态。

讲解：检索在受控资料库内执行；问题匹配、时效和同源检查是确定性步骤。检索相关不等于内容真实，仍要核实来源，也不据相关性认定经营因果。

## 定价对假设的依赖

计算一个候选促销，向下查看5档价格与3档弹性的对比。在库存、预算相同的情况下，说明需求假设如何改变费用后贡献，而非只展示一个确定的“最优价格”。

## 试点设计

进入会员与策略中心的“试点与评测”，估算从8%到9.5%转化率差所需样本。运行模拟样例，查看转化和贡献区间。说明模拟只是流程验证，真实试点应预先设定分流、周期和停止条件。

可以导入匿名用户级CSV。故意重复一个用户ID，展示拒绝重复用户，避免把重复触达误当独立样本。

## 内容与审核

先展示AI素材库与来源记录，播放有声MP4；说明静态图生成、视频合成和语音的各自方式。再从促销方案生成脚本并核对；修改活动说明后，检查审核失效，避免旧审核覆盖新内容。

## 可追溯交付

打开项目与价值管理中的运行记录，查看促销、研究、脚本与核对的冻结输入输出。强调当前为浏览器端记录，真实企业落地需要服务端身份、权限、审计与持久化。
