# v0.2.0 验收记录

日期：2026-11-23。

## 修复和新增

1. 移除所有问题共享默认报告的逻辑。中文双字词TF-IDF与主题过滤筛选相关资料，按问题识别门店、区域及7/28/90天范围；无匹配证据时不给出外部事实结论。
2. 保留来源时效、同源去重与原文引用；将匹配证据、原因假设和下一步动作分别呈现。
3. 促销计算新增5档价格×3档弹性的敏感性分析，保留库存、费用和最低贡献约束。参数拒绝非有限数、负库存及非法价格。模型请求期间修改内容后，迟到结果会被丢弃，避免覆盖新输入。
4. 新增样本量规划、匿名用户级CSV、重复用户校验、转化差与每用户贡献差及95%近似区间。模拟和导入来源分开标注。
5. 内容审核绑定商品、价格、活动说明和分镜版本；修改输入后需重新核对。运行输入、输出、来源和时间形成浏览器端快照，可导出。
6. 新增真正由AI工具生成的虚构商品素材、提示词记录与有声15秒MP4。配音经时长适配后完整容纳于成片。
7. 模型接口补充权威商品名称复核、输入与输出检查、同源和Host检查、大小限制及超时处理；兼容无密钥的本地Ollama配置。
8. 增加Linux/Windows CI工作流与锁定的DOM测试依赖；GitHub远程运行结果待实际观察。
