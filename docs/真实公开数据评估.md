# UCI Online Retail真实数据验证

## 来源与范围

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33。

原始数据：https://archive.ics.uci.edu/dataset/352/online+retail 。许可CC BY 4.0。来源是英国注册的非实体店零售商，主要销售礼品，含批发客户。日期2010-12-01至2011-12-09，金额单位为英镑。

原始ZIP SHA-256：f5385cbb54bbebf7196389109c6b0621faab0c304e3702548165e71c84aede8b。

本项目导出了汇总、评估结果及少量摘要展示编码，没有把原始CustomerID或整个原始工作簿放入仓库。

## 清洗与金额

原始541,909行，保留536,494行。排除2,894行列明的非商品代码，以及2,521行非正价格记录。具体StockCode清单在脚本和JSON中公开，属于本项目分析口径，不将它包装为UCI官方统一口径。

单价采用Decimal四舍五入到便士，再乘数量。取消发票（C开头）及负数量作为负向交易，按自身发生日期汇总；没有逐笔匹配原始销售。缺失CustomerID的131,618行仍进入经营汇总，但不进入用户级推荐评估。保留源文件重复行，源数据未证明它们属于误重复。

正向金额£10,283,180.93，取消/负向金额£478,724.18，差额£9,804,456.75。该差额不是利润。没有成本、库存、门店客流和活动分流字段，不补造这些数据。

2011年12月只到9日，页面明确标为不完整月。

## 推荐对照

- 仅使用国家字段为United Kingdom、CustomerID非空、正向购买发票。
- 训练截止2011-11-09；测试2011-11-10至2011-12-09。
- 候选商品：按训练期发票出现频次选前500种，不使用未来销量选品。
- 两种算法均过滤训练期已购；对照为热门推荐，候选为商品篮共现余弦相似度加购买强度及热门回退。
- 超过100个候选SKU的14个批发大篮子不参与共现学习，经营汇总不排除这些交易。
- 1,019名有训练历史且未来未购商品落入候选集合的用户进入指标分母；指标为用户宏平均。

| 指标 | 热门基线 | 商品篮关联 |
| --- | --- | --- |
| HitRate@10 | 0.232581 | 0.383710 |
| Recall@10 | 0.041212 | 0.104672 |
| NDCG@10 | 0.042576 | 0.102637 |

候选集合覆盖未来未购商品的比例为0.364896。未满足候选与用户条件的购买不进入以上指标分母，因此不能把结果推广到整个商品集合或所有顾客。

用户配对NDCG差值95%Bootstrap区间：[0.050102, 0.070669]，固定种子20261123，重采样1000次。它反映评估用户间差异，不是因果收益，也不证明上线转化会相应增长。

## 重建

应用运行不需要openpyxl或原始22.6MB工作簿。若需要独立复核整个数据处理过程：

```powershell
python -m pip install -r requirements-analysis.txt
python scripts/build_public_benchmark.py --download
```

也可用--archive指定已下载的ZIP。脚本先核对哈希，再读取源数据，生成dist/assets/public-retail.json、dist/public-data.js与docs/public-benchmark.json。原始下载保留在被Git忽略的work目录中。
